## Step 6 — verification

Automated:
- `read_console` shows no errors or warnings from the new code.
- All EditMode tests pass (package tests resolve from the release tag, plus BD `EditModeTests`).

Manual, in GameScene in Play Mode (UnityMCP play + console, then you listen on device/Editor):
1. BGM starts and loops.
2. Placing a block plays `sfx_place_block`.
3. Clearing one or more lines plays `sfx_line_clear` once per move.
4. Game over → LoseCanvas plays `sfx_game_over`.
5. SettingPopup: the SFX toggle silences SFX, the music toggle silences BGM, and both come back when toggled again.
6. Restart the game with mute ON → it stays muted (read from `GameData.setting` at `Start`).
7. Open/close a popup and press buttons: no exceptions (CLICK / POPUP_* have no entries → silent, one Editor warning each).
