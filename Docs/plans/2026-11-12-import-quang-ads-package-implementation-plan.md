## Steps

### 1. Add the package

Add this line to `Packages/manifest.json` after `com.quang.services.analytics`:

```json
"com.quang.services.ads": "https://github.com/Quangbipi/Package_Release.git?path=Packages/com.quang.services.ads#release-2026.11.03.2",
```

Refresh Unity (`refresh_unity`) and wait for the package to resolve.

Check:
- `Library/PackageCache/com.quang.services.ads@*` exists and `package.json` says `0.8.3`.
- The console shows no compile errors, and no `Quang.Ads.Integration.*` assembly is built (no `QUANG_ADS_*` define).

### 2. Add `AdsBootstrap`

1. Add `"GUID:9742c66c119bec84bbdcab3c9bcf9bd6"` to `references` in `BlockDrag.asmdef`.
2. Create `Assets/_Game/_BlockDrag/Ads/AdsBootstrap.cs`:

```csharp
using Quang.Ads;
using Quang.Base;
using UnityEngine;

namespace Gameplay.BlockDrag.Ads
{
    /// <summary>
    /// Registers a no-op ads service until a real mediation SDK (AdsManager) is added.
    /// A real AdsManager assigns Locator.Ads in Awake, after this, and replaces it.
    /// </summary>
    public static class AdsBootstrap
    {
        [RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.BeforeSceneLoad)]
        static void Init()
        {
            Install();
        }

        public static void Install()
        {
            if (Locator.Ads == null)
            {
                Locator.Ads = new NullAdsService();
            }
        }
    }
}
```

3. Refresh Unity and check the console for errors.

### 3. Add EditMode tests

1. Add `"GUID:9742c66c119bec84bbdcab3c9bcf9bd6"` to `EditModeTests.asmdef`.
2. Create `Assets/Tests/EditMode/AdsBootstrapTests.cs`. `SetUp` / `TearDown` save and restore `Locator.Ads`. Tests:
   - `Install_WhenAdsIsNull_AssignsNullAdsService`
   - `Install_WhenAdsAlreadyRegistered_KeepsExistingService` (uses a second `NullAdsService` instance and checks it is the same reference)
   - `NullRewardShow_InvokesHiddenOnly_WithoutReward`
   - `NullInterShow_InvokesContinuation`
3. Run EditMode tests (`run_tests`, EditMode). All tests pass, including the existing ones and `Quang.Ads.Tests` if the Test Runner lists them.

### 4. Update architecture doc

In `.agents/rules/architecture.md`, change the `Quang.Ads` row to say: installed (`com.quang.services.ads` 0.8.3), no vendor define set, and `BlockDrag/Ads/AdsBootstrap` registers `NullAdsService` at `BeforeSceneLoad` until `AdsManager` is added.

### 5. Manual check in the Editor

1. Open `LoadStart`, press Play and go into a game.
2. Console has no errors. With `execute_code`, or a debug log, confirm `Locator.Ads` is a `NullAdsService` after load.
3. Play until out of moves. The revive flow still works as before.
